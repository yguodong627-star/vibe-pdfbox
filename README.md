# 页匠 · PDF 工具箱

合并、拆分、整理、加页码、**加水印、手写签名/图片签章、PDF 转图片**、图片转 PDF，以及一个诚实的“重新渲染压缩”。**文件只在浏览器里处理，不会上传**——页面没有任何上传请求，打开后断网也能用。完全免费，没有 Pro、授权码、次数或大小限制。

在线使用：https://ysdtn.com/vibe-pdfbox/（仓库 Pages：https://yguodong627-star.github.io/vibe-pdfbox/）

## 功能

| 工具 | 说明 |
|---|---|
| 合并 | 多个 PDF 按顺序拼成一个，拖动手柄或点箭头排序 |
| 拆分 / 提取 | 输入 `1-3, 5, 8-` 或点缩略图选页；奇数页、偶数页一键选 |
| 整理页面 | 缩略图上直接左转/右转、删除、拖拽排序，导出新文件 |
| 加页码 | 6 个位置、4 种格式、起始数字、跳过前几页；已旋转的页面也会摆正 |
| **水印** | 文字水印：位置（9 宫格）/ 平铺、透明度、旋转 -90°~90°、字号、颜色；作用于全部页或指定页（`1-3, 5`）；实时预览 |
| **签名签章** | 画布手写（笔色、粗细）或上传签名/公章图片（可去白底）；拖到页面任意位置、调大小，可在多页放多个；嵌入后下载 |
| **转图片** | 每页导出 PNG / JPG；72/96/150/200/300 DPI；JPG 质量可调；可只转指定页；单页直出图片，多页打 ZIP |
| 图片转 PDF | JPG/PNG/WebP 等，A4 / Letter / 与图片等大，自动按 EXIF 摆正手机照片 |
| **压缩（重新渲染）** | 把每页渲染成 JPEG 再合成 PDF，导出后显示前后体积（见下方限制） |

## 水印与签名的实现细节（说实话）

- **英文/数字水印写成真正的 PDF 文字**（Helvetica），可被 `pdftotext` 提取、可搜索；含中文等非拉丁字符时，浏览器里把文字渲染成透明 PNG 再嵌入——视觉一致，但**文字不可选中、不可搜索**。界面会提示。原因：内置 CJK 字体子集会让页面体积增加数 MB，不符合“零配置、轻量”。
- 水印按页面**视觉方向**定位，对带 `/Rotate` 的页面（常见于扫描件）自动换算坐标，测试中旋转 90° 的页面水印同样居中、方向正确。
- 签名是**图像签名**，不是带数字证书的电子签章（不做 PKI/时间戳），不具备防篡改能力，法律效力请自行确认。
- 画布手写在触屏上可用（Pointer Events），上传图片的“去白底”是简单阈值算法，扫描底色不均匀时可能留下灰边——可改用“保留白底”。

## 压缩：只做一种诚实的办法

不假装做无损压缩。这里的“压缩”= **每页重新渲染为 JPEG 图片再生成 PDF**：

- 输出每页都是图片：**文字不再可选/可搜索/可复制，链接、书签、表单全部丢失**；
- 效果有限：对扫描件、大图 PDF 效果明显（自测 3 页噪点扫描件 96 DPI 档体积显著下降），对本来就是文字+矢量的 PDF 往往**反而变大**，界面会明确提示“反而变大了”；
- 不做 OCR，不会把图片文字找回来。

## 完全免费

没有任何功能锁、次数或大小限制。文件只在你的浏览器里处理，不上传。唯一的实际上限是浏览器可用内存（特别大的 PDF 在手机上可能较慢）。转图片的单页画布有安全上限（单边 8000 像素 / 6000 万像素），超出会自动降低分辨率并提示。

## 本地运行

纯静态文件，没有构建步骤。

```bash
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

不要直接双击 `index.html` 以 `file://` 打开——浏览器会拦截 pdf.js 的 Worker。

## 依赖（均已放在 `vendor/`，不走 CDN）

- [pdf-lib](https://github.com/Hopding/pdf-lib) 1.17.1（MIT）：读写、合并、拆分、旋转、画页码/水印/签名
- [pdf.js](https://github.com/mozilla/pdf.js) 3.11.174（Apache-2.0）：渲染缩略图、转图片、压缩
- 字体 Instrument Serif / Inter 自托管于 `vendor/fonts/`（沿用 ysdtn.com 的字体文件），中文回退宋体/苹方/微软雅黑

## 测试

```bash
python3 -m http.server 8768 &
export NODE_PATH=/path/to/node_modules   # 需 puppeteer-core、本机 Chrome、Pillow、poppler-utils
node tests/smoke.js      # 原有功能（合并/拆分/页码/图转 PDF、无限额）
node tests/features.js   # 新功能：用 pdftotext / pdftoppm / pdfinfo + Pillow 抽查输出
node tests/shots.js      # 重新生成 screenshots/
```

`features.js` 覆盖：水印文字用 `pdftotext` 验证、居中位置/方向（A4、Letter、旋转 90 页）、指定页、平铺、中文水印；签名拖放位置与渲染后像素质心比对（含旋转页）；PNG/JPG 转图片尺寸（150 DPI 的 A4 = 1240×1754）；压缩体积与“文字不可选”；无外部请求。

## 已知限制

- 有密码的 PDF 打不开，会提示。
- 合并/拆分用 pdf-lib 复制页面，书签、表单域、部分交互元素不会保留；水印/签名/页码会保留原有内容，但不会处理已有数字签名（加内容会使原数字签名失效）。
- 页码用内置英文字体，不支持“第 1 页”这类中文样式。
- 非拉丁水印是图片（见上）；水印以 MediaBox 为基准，极少数设置了特殊 CropBox 的文件位置可能略有偏差。
- 图片会重新编码（JPEG 质量 0.92，最长边限制 4200px），不是无损嵌入。
- 单页缩略图在超大文件（几百页）上会比较慢，内存占用随文件变大。
- 不含 OCR、转 Word。
