# 页匠 · PDF 工具箱

合并、拆分、旋转、删页、拖拽重排、加页码、图片转 PDF。**文件只在浏览器里处理，不会上传**——页面里没有任何上传请求，打开后断网也能用。

在线使用：https://ysdtn.com/vibe-pdfbox/

## 功能

| 工具 | 说明 |
|---|---|
| 合并 | 多个 PDF 按顺序拼成一个，拖动手柄或点箭头排序 |
| 拆分 / 提取 | 输入 `1-3, 5, 8-` 或点缩略图选页；奇数页、偶数页一键选 |
| 整理页面 | 缩略图上直接左转/右转、删除、拖拽排序，导出新文件 |
| 加页码 | 6 个位置、4 种格式、起始数字、跳过前几页；已旋转的页面也会摆正 |
| 图片转 PDF | JPG/PNG/WebP 等，A4 / Letter / 与图片等大，自动按 EXIF 摆正手机照片 |

## 免费版与 Pro

- 免费：单文件 20MB 以内、每天 10 次导出、一次最多合并 5 个文件、图片转 PDF 最多 20 张。
- Pro：不限制上述额度；批量加页码、按范围/逐页拆成多个文件，打包 ZIP。
- 授权码入口已做好，但**购买渠道未接入**。`app.js` 里的 `keyOk` 只是占位校验（本地校验和），谁都能算出来，**不能当真正的防盗版**。正式发售时请改为服务端签发 + 本地公钥验签，且不要把私钥放进前端。

## 本地运行

纯静态文件，没有构建步骤。

```bash
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

不要直接双击 `index.html` 以 `file://` 打开——浏览器会拦截 pdf.js 的 Worker。

## 依赖（均已放在 `lib/`，不走 CDN）

- [pdf-lib](https://github.com/Hopding/pdf-lib) 1.17.1（MIT）：读写、合并、拆分、旋转、画页码
- [pdf.js](https://github.com/mozilla/pdf.js) 3.11.174（Apache-2.0）：渲染缩略图

## 已知限制

- 有密码的 PDF 打不开，会提示。
- 合并/拆分用 pdf-lib 复制页面，书签、表单域、部分交互元素不会保留。
- 页码用内置英文字体，不支持“第 1 页”这类中文样式。
- 图片会重新编码（JPEG 质量 0.92，最长边限制 4200px），不是无损嵌入。
- 单页缩略图在超大文件（几百页）上会比较慢，内存占用随文件变大。
- 不含压缩、OCR、转 Word。
